
## 로컬 미리보기

Docker Desktop을 실행한 뒤 아래 명령을 실행한다.

```bash
docker compose up --build
```

브라우저에서 [http://localhost:4000](http://localhost:4000)을 연다. 파일을 수정하면 LiveReload가 페이지를 자동으로 새로고침한다.

종료할 때는 터미널에서 `Ctrl+C`를 누른다. 컨테이너를 정리하려면 다음 명령을 실행한다.

```bash
docker compose down
```
